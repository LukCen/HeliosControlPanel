# Helios Control Panel

Proste narzędzie devops zaprojektowane na własne potrzeby - jako praktyka Electrona i ogólnego rozwijania aplikacji, głównie do zarządzania lokalnym serwerem - nawiązywanie i monitorowanie połączeń i przesyłanie plików bez konieczności kontaktu z maszyną serwera.


Simple dev tool designed for personal use, for establishing and managing connections with external servers.

This is an updated version of my old repo, which never left the dev stage (main branch of this repo) - changes included a modification into an SPA style, inclusion of TypeScript and Tailwind, and ESBuild and general streamlining and removal of hard-coded values.
